## 4. Модель данных

Каталог и концерты рендерятся из JSON, чтобы добавление релиза было правкой одного файла, а не HTML.

**`data/releases.json`**
```json
[
  {
    "title": "КОНИ",
    "subtitle": "Signature Version",
    "year": 2026,
    "date": "2026-08-21",
    "cover": "photo/koni-pre-save.webp",
    "smartlink": "https://link.1mp.ru/knsv",
    "featured": true
  }
]
```

**`data/shows.json`**
```json
[
  {
    "date": "2026-11-14",
    "city": "Москва",
    "venue": "название площадки",
    "status": "onsale",
    "tickets": "https://victorr.ticketscloud.org/"
  }
]
```

Правила рендера:

- `featured: true` — карточка наверху секции «Слушать» со статус-плашкой. Ровно один featured; если их несколько — берётся первый, в консоль предупреждение.
- Названия треков выводятся **ЗАГЛАВНЫМИ** — это правило бренда (КОНИ, НЕ ГЕРОЙ, ПОТЕРЯТЬ). Приводить к верхнему регистру в CSS через `text-transform`, а не в данных.
- `shows.json` пустой → секция дат показывает состояние «Ближайшие даты объявляются в Telegram» + кнопка. **Секцию не скрывать.**
- Кнопка `БИЛЕТЫ` появляется только при `status: "onsale"`.
- Каталог сортируется по `date` по убыванию.
- Оба файла грузятся через `fetch` при загрузке страницы. Если fetch упал — секция показывает статичный фолбэк с текущим релизом, а не пустоту.

Сейчас на витрине Яндекса 3 трека из 12; когда каталог выложат целиком, дополняется только `releases.json`, вёрстка не трогается.

## 6. Конвенции кода

- Только ванильный JS. Без зависимостей, без CDN, без модульных бандлеров. `<script type="module">` допустим — работает нативно.
- CSS: сначала `@font-face`, потом `:root` с токенами, потом секции в порядке страницы. Никаких магических чисел мимо токенов.
- Мобильный первым: базовые стили без медиазапросов = 375, медиазапросы наращивают.
- Комментарии по-русски, коротко: **зачем** блок, а не что делает строка.
- Никаких `!important` (в текущем CSS их два, в медиазапросе 600px — уйдут вместе с переверсткой).
- `getBoundingClientRect` в layout-коде запрещён — только CSS.
- Имена классов по секциям: `hero__title`, `listen__grid`, `live__cta`.
