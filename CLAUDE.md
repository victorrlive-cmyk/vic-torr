# vic-torr.com — контекст проекта для Claude Code

Одностраничный статический сайт-визитка Vic Torr. Хостится на GitHub Pages,
домен `www.vic-torr.com` (файл `CNAME`), репозиторий `victorrlive-cmyk/vic-torr`,
рабочая ветка `main`. Сборки нет — что лежит в репозитории, то и в проде.

## 🔒 Железные правила (не нарушать)

1. **Никаких фреймворков и сборки.** Ни React, ни Tailwind, ни npm, ни бандлера.
   Только `index.html` + локальные ассеты. Всё CSS — инлайн в `<head><style>`,
   весь JS — в двух инлайн-`<script>` в конце `<body>`.
2. **Ничего не ломать на GitHub Pages.** Пути к ассетам — как сейчас, `.nojekyll`
   не удалять, `CNAME` не трогать. Никаких шагов, требующих билда.
3. **Правки точечные.** Не переписывать файл целиком, не «причёсывать» вёрстку
   заодно. Изменил кнопку — изменил кнопку.
4. **Существующий макет и типографика — данность.** Тёмный постерный минимализм,
   uppercase + широкий letter-spacing. Менять только когда Vic прямо попросил.
5. **Кнопки и ряд иконок всегда по центру и адаптивные** на всех ширинах.
6. **Не коммитить и не пушить без запроса.** Прод обновляется пушем в `main`
   мгновенно — это публикация, её решает Vic.

## Запуск и проверка

Live Server (расширение `ritwickdey.liveserver`) на порту **5500**:
правый клик по `index.html` → **Open with Live Server** (⌘L ⌘O) →
`http://127.0.0.1:5500/index.html`.

Проверять после каждой правки вёрстки на трёх ширинах: **1280** (двухколоночная
карточка), **860** (переход в одну колонку), **375** (iPhone, иконки в 3 ряда).

## Дизайн-система (значения из `index.html`, не выдумывать новые)

| Роль | Значение |
|---|---|
| Фон страницы | `#07080b` |
| Текст | `#f3f4f6` |
| Акцент («ссылки», кнопка концертов) | `--accent-links: #ff2d2d` / `rgba(255,59,48,…)` |
| Поверхности | `rgba(255,255,255,.02….10)` на тёмном |
| Границы | `rgba(255,255,255,.10….24)` |
| Радиусы | карточка 22px · блоки 14–16px · кнопки/иконки 12px · пилюля 999px |
| Шрифт | системный стек `ui-sans-serif, system-ui, -apple-system…` — веб-шрифтов нет |
| Ховер | `translateY(-1px)` + подсветка фона/границы, `transition .12s ease` |

Типографика заголовков и кнопок: `text-transform: uppercase`, `letter-spacing`
от `.10em` до `.22em`, `font-weight` 700–900. Мелкие подписи — 10–13px с
`opacity: .62….86`.

## Как устроен макет

```
.bg (фикс. размытое фото)  →  .vignette  →  .wrap  →  .card (grid 1fr / 1.15fr)
                                                       ├── .poster   (ч/б фото)
                                                       └── .content  (всё остальное)
```

Внутри `.content` по порядку: `header` (h1 / .sub / .cities / .tagline) →
`.links` (кнопки `.btns` + промо-карточка + `.section-title` + `.icon-row`) →
`.video-block` (YouTube iframe 16:9) → `.quotes` (be/en/ru) → `.footer`.

Кнопка «концерты» (`.tourlink`) закомментирована в разметке — стили оставлены
намеренно, чтобы её можно было вернуть одной строкой.

## Хрупкие места (сюда лезть аккуратно)

1. **JS-синхронизация ширины `.links` и `.icon-row`** (второй `<script>`).
   Скрипт считает ширину как «две кнопки + gap» и выставляет её `.links` и
   `.icon-row`, плюс сдвигает ряд иконок на `offset` от левого края первой кнопки.
   Значит: `a.btn { min-width: 210px }` и `.btns { gap: 12px }` — **входные данные
   для JS**. Меняешь их — обязательно перепроверяй выравнивание на десктопе.
   На ширине ≤860px скрипт сбрасывает инлайн-стили и отдаёт всё CSS.
2. **Брейкпоинты 860px и 600px** дублируют часть правил. Правка десктопного
   стиля почти всегда требует взгляда в оба медиазапроса.
3. **Пути к ассетам смешанные:** favicon и manifest — абсолютные (`/favicon/…`),
   картинки — относительные (`./images/…`). Абсолютные работают на Pages и на
   Live Server от корня, но ломаются при открытии файла через `file://`.
   Новые ассеты подключать **относительными** путями.
4. **Иконки стримингов** — монохромные SVG, вид задаётся CSS-фильтрами
   (`grayscale(1) contrast(3.0)`). Модификаторы: `.high-contrast` (Яндекс.Музыка,
   иначе тонет) и `.wide` (КИОН, широкий знак). Новый логотип — сначала посмотреть,
   как он выглядит под базовым фильтром, и только потом вешать модификатор.
5. **`.promo-card`** держит фоном `photo/vic_torr_zero_hero.png` и затемняющий
   градиент. Меняется картинка релиза → проверить читаемость белой надписи на ней.
6. **Ссылки на стриминги** зашиты в разметку с ID артиста. При смене ссылки
   менять её в **обоих** местах: в `.btns` и в `.icon-row` (Spotify и Яндекс
   дублируются).

## Проверка перед коммитом

- Открыть в Live Server и посмотреть 1280 / 860 / 375.
- Консоль браузера чистая, ряд иконок выровнен по кнопкам.
- Все пути к ассетам живые (favicon, логотипы, фото, iframe).
- Ничего не добавилось из внешних CDN и не появилось шагов сборки.
