# vic-torr.com — контекст проекта для Claude Code

Одностраничный статический сайт Vic Torr. Хостится на GitHub Pages,
домен `www.vic-torr.com` (файл `CNAME`), репозиторий `victorrlive-cmyk/vic-torr`,
рабочая ветка `main`. Сборки нет — что лежит в репозитории, то и в проде.

## 🔒 Железные правила (не нарушать)

1. **Никаких фреймворков и сборки.** Ни React, ни Tailwind, ни npm, ни бандлера.
   Только `index.html` + `style.css` + `main.js` (ванильный JS) + локальные ассеты.
   Стили — классами в `style.css`, без инлайн-стилей в разметке.
2. **Ничего не ломать на GitHub Pages.** `.nojekyll` не удалять, `CNAME` не трогать.
   Никаких шагов, требующих билда.
3. **Правки точечные.** Не переписывать файлы целиком, не «причёсывать» вёрстку
   заодно. Изменил кнопку — изменил кнопку.
4. **Макет — данность.** Референс лежит в `_handoff/` (README + `design/VicTorrPage.dc.html`).
   Тексты, цвета, шрифты и ссылки — строго по нему. Тексты Vic не переписывать без запроса.
5. **Не коммитить и не пушить без запроса.** Прод обновляется пушем в `main`
   мгновенно — это публикация, её решает Vic.
6. **`_handoff/` на сайт не попадает** (в `.gitignore`), из сайта на него не ссылаться.

## Структура

```
vic-torr/
  index.html        ← разметка всех секций + pop-up политики (<dialog id="privacy">)
  style.css         ← @font-face, токены в :root, все стили; брейкпоинт 640px
  main.js           ← скролл к #platforms, форма BOOKING, pop-up политики
  fonts/            ← Fira Sans / Fira Sans Extra Condensed, woff2 (кириллица + латиница)
  images/           ← logo-yellow.svg, vic-hero-*.webp, fur-bg.jpg,
                      logo-*.svg (6 стримингов), cover-*.webp (обложки 1200×1200)
  docs/             ← EPK и техрайдер (PDF), на них ведут кнопки букинга
  media/            ← видео главной (mp4 + постер jpg), см. «Видео на сайте»
  tools/            ← make-web-video.sh — сжатие видео для сайта
  house-of-rock/    ← закрытая промо-страница (noindex, без ссылки с главной), свои media/
  favicon/          ← иконки + site.webmanifest
  CNAME, .nojekyll
  .github/copilot-instructions.md  ← краткие правила для Copilot
  _handoff/         ← макет, ТЗ и booking-worker.js (локально, не публикуется)
```

## Запуск и проверка

`python3 -m http.server 8000` в корне → `http://localhost:8000`, либо Live Server
(порт 5500). Сверка с макетом: `http://localhost:8000/_handoff/design/preview-3-widths.dc.html`.

Проверять на трёх ширинах: **375**, **860**, **1280**.

## Как устроена страница

`header.hero` → `main`: `#listen` (01 — релизы, «Смотреть» с вертикальными видео, `#platforms`)
→ `#live` (02 — видео, `#booking`, ближайшие даты) → `#diary` (03 — сразу после лайва,
пока эмоция живая) → `#about` (04 — био, регалии, цитата) → `#contacts` (05) + `footer`
→ `dialog#pick` (где слушать трек) → `dialog#privacy`.

## Хрупкие места

1. **Первый экран** — одна разметка на обе ширины. До 640px фото
   `vic-hero-stage3.webp` полосой 445px, с 640px — `vic-hero-mono.webp` на весь блок
   и дополнительное боковое затемнение `.hero__side`. Правишь hero — смотри оба варианта.
2. **Атрибут `hidden`** работает благодаря `[hidden] { display: none !important; }`
   в `style.css`. Без этого правила форма и плашки, у которых в CSS есть `display`, видны всегда.
3. **Обложки** круглые с прозрачными углами: `.cover` — квадрат, `object-fit: contain`,
   без фона, скругления и обрезки. Новую обложку класть 1200×1200 в `images/`.
4. **Форма BOOKING:** адрес Worker'а — константа `BOOKING_ENDPOINT` в начале `main.js`.
   Пустая строка → отправка через `mailto:`. Серверная часть — `_handoff/server/booking-worker.js`.
5. **Политика обработки данных** — `<dialog id="privacy">`, открывается любой ссылкой
   с атрибутом `data-privacy`. Нужна по 152-ФЗ, потому что форма собирает контакты.
6. **Ссылки:** внешние — `target="_blank" rel="noopener"`, `mailto:` — без target.
   Ссылки на релизы и стриминги зашиты в `index.html`.
7. **Пути:** favicon и manifest абсолютные (`/favicon/…`), всё остальное относительное.
   Новые ассеты подключать относительными путями.

## Видео на сайте (вместо YouTube — в РФ он грузится плохо)

- Только MP4: H.264 High yuv420p + AAC 128k стерео 48 kHz, `faststart`, без метаданных и data/timecode-дорожек.
- Кадр: горизонтальное 1280×720, вертикальное 720×1280. `crf 23–24` + `-maxrate`:
  вертикальное 2.5M, горизонтальное 1.5M (длинное) … 2M (короткое).
- Файл ≤ 50 МБ (лимит GitHub 100 МБ), сайт ≤ 1 ГБ. Больше 50 — снизить maxrate на 0.2–0.3M.
- Жать только из исходника, уже сжатое не перекодировать. Промежуточные версии не коммитить.
- Постер обязателен: JPG того же размера, q85, ≤ 150 КБ. Своя обложка Vic в приоритете,
  иначе живой кадр (не титр, не плашки).
- Имена: латиница, строчные, через дефис: `name.mp4` + `name-poster.jpg`.
- Сжатие: `bash tools/make-web-video.sh <исходник> <имя> [maxrate]` из корня → `media/`.
- Встраивание: `<video controls playsinline preload="none" poster="media/NAME-poster.jpg">`
  + `<source src="media/NAME.mp4" type="video/mp4">`. Без автоплея; mp4 не должен качаться
  до Play. Жёлтая Play поверх постера — `.video__play` (main.js включает controls после старта).
- Путь `media/` держать единым: при переезде в Yandex Object Storage / Selectel меняется только префикс.
